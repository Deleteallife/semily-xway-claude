# Semily XWAY Studio для Claude Code

Плагин для [Claude Code](https://code.claude.com): анализ конкурентов на Wildberries, генерация пяти обложек, A/B-тест изображений в XWAY по CTR и применение подтверждённого победителя.

Это порт скилла Semily XWAY Studio 1.0.3 с Codex на Claude Code. Версия для Codex — в отдельном репозитории [semily-xway-codex](https://github.com/Deleteallife/semily-xway-codex).

## Установка

В Claude Code выполните две команды:

```bash
/plugin marketplace add Deleteallife/semily-xway-claude
```

```bash
/plugin install semily-xway-studio@semily
```

Затем подключите аккаунт Semily:

```bash
/mcp
```

Выберите `semily_xway` → **Authenticate** и завершите вход в браузере. Вход нужен один раз, дальше токен обновляется сам.

Если после установки Claude Code написал `Run /reload-plugins to activate.` — выполните:

```bash
/reload-plugins
```

### Без интерактивной панели

В обычном терминале (без запущенной сессии):

```bash
claude plugin marketplace add Deleteallife/semily-xway-claude
```

```bash
claude plugin install semily-xway-studio@semily
```

```bash
claude mcp login semily_xway
```

### В десктопном приложении Claude

Откройте браузер плагинов в приложении и добавьте маркетплейс `Deleteallife/semily-xway-claude`, затем установите `semily-xway-studio`.

## Использование

Короткая команда на весь цикл:

```
/semily-xway-studio:start 123456789
```

Приложите к сообщению фото товара и, если есть, референс фона и текстовый макет.

Дополнительные команды:

| Команда | Что делает |
| --- | --- |
| `/semily-xway-studio:start [артикул]` | Полный цикл: анализ WB → пять обложек → подтверждение → запуск XWAY |
| `/semily-xway-studio:status [артикул]` | Срез теста: показы, клики, CTR по контролю и V1–V5 |
| `/semily-xway-studio:winner [артикул]` | Проверка порогов и применение победителя, затем следующий цикл |

Команды можно не использовать: скилл подхватывается автоматически, когда вы просите проанализировать конкурентов на WB, сделать обложки или запустить тест XWAY.

## Что делает скилл

1. **Анализ WB.** Первые 20 органических карточек по запросу: фон, композиция, контраст, текст, бейджи, читаемость в миниатюре. Наблюдения отделены от выводов.
2. **Пять гипотез V1–V5.** Каждая меняет один основной рычаг и различима на превью 150 px. Товар, логотип, текст на упаковке и количество сохраняются без изменений.
3. **Доставка.** Все пять изображений показываются вам целиком, а не ссылками и не именами файлов.
4. **Одно подтверждение.** `ОК` / `да` / `запускай` — и тест уходит в XWAY: чемпион + V1–V5, шесть кадров.
5. **Решение по CTR.** Победитель засчитывается только при ≥1500 показов у контроля и кандидата, приросте от +1,5 п.п. и p-value < 0,05. Выручка на 1 000 показов для решения не используется.
6. **Следующий цикл.** Победитель становится чемпионом, к нему создаются пять новых челленджеров.

## Требования

- Claude Code v2.1.186 или новее (для `claude mcp login`); интерактивная панель `/mcp` работает и на более ранних версиях.
- Аккаунт Semily с доступом к XWAY.

## Подключение к серверу

Плагин объявляет удалённый MCP-сервер:

| Параметр | Значение |
| --- | --- |
| Имя | `semily_xway` |
| URL | `https://plugin.semily.ru/mcp` |
| Транспорт | Streamable HTTP |
| Scopes | `mcp:use`, `offline_access` |
| OAuth callback | `http://localhost:4321/callback` |

Плагин использует фиксированный публичный OAuth Client ID, поэтому динамическая регистрация клиента не выполняется и ошибка `403 too_many_entities` не возникает.

Пароли, токены и доступ к БД в репозиторий не входят и никогда не запрашиваются в чате.

## Диагностика

**`Callback URL mismatch` при входе.** В настройках OAuth-приложения должен быть разрешён `http://localhost:4321/callback`. Claude Code v2.1.229 отправлял вместо него `http://127.0.0.1:4321/callback` — обновите Claude Code или временно разрешите обе формы.

**Инструменты `semily_xway` не видны.** Выполните `/mcp` и проверьте статус сервера. Если он `needs authentication` — пройдите вход заново.

**Плагин установлен, но скилл не появился.** `/reload-plugins`, а если не помогло — `rm -rf ~/.claude/plugins/cache`, перезапуск Claude Code и переустановка плагина.

**Порт 4321 занят.** Освободите порт на время входа: он нужен только на несколько секунд для OAuth-редиректа.

## Ручная установка без плагина

Если нужен только скилл, без системы плагинов — см. [scripts/](scripts/):

```bash
powershell -ExecutionPolicy Bypass -File .\scripts\install.ps1
```

```bash
bash scripts/install.sh
```

Скрипт копирует скилл в `~/.claude/skills/semily-xway-studio` и регистрирует MCP-сервер. Удаление — `uninstall.ps1` / `uninstall.sh`.
