# Semily XWAY Studio

Плагин Claude Code для цикла: анализ WB → пять обложек → тест XWAY → победитель по CTR → следующий цикл.

## Состав

| Компонент | Путь |
| --- | --- |
| Скилл | `skills/semily-xway-studio/SKILL.md` |
| Справочники | `skills/semily-xway-studio/references/` |
| Команды | `commands/start.md`, `commands/status.md`, `commands/winner.md` |
| MCP-сервер | `.mcp.json` → `semily_xway` (https://plugin.semily.ru/mcp) |

## Установка

```bash
/plugin marketplace add https://github.com/Deleteallife/semily-xway-claude
```

```bash
/plugin install semily-xway-studio@semily
```

```bash
/mcp
```
